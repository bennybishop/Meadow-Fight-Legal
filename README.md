`index.html` is the policy source. The site uses GitHub Pages, publishing from `main` at `/`.

## Release maintenance

Before each store release, the developer and publisher should check this policy against the final SDK configuration, audience selection, consent flow and Google Play Data safety answers. SDK presence alone does not prove collection by every integrated network. The current text is based on the Meadow Militia Unity source and SDK integrations examined on 30 October 2026. The policy URL should also be accessible from inside the app.

Do not publish SDK keys, private Unity sources, player identifiers or support correspondence in this public repository.
